Khi nào bắt buộc dùng heap?
Khi số phần tử chỉ biết lúc chạy, ví dụ người dùng nhập n.
if (scanf("%d", &n) != 1) return 1;
int *a = malloc(n * sizeof(int));
if (a == NULL) return 1;
/* ... dùng a[0] .. a[n-1] ... */
free(a);

Con trỏ và bộ nhớ · 10
Lỗi 1 và 2
LỖI 1
Con trỏ NULL
*a = 5; // a == NULL
Ghi vào ô không tồn tại: chương trình crash ngay.
LỖI 2
Dùng sau free
free(a); a[0] = 1;
Đọc/ghi ô đã trả: hành vi không xác định, khó bắt nhất.
