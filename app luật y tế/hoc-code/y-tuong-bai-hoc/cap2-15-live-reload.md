# Thư viện nạp lại code khi chạy

**Cấp 2 · Trung bình** · Nguồn: Live Code-reloader Library

## Mục tiêu
Hiểu thư viện động (.so/.dll) và nạp lại hàm lúc chạy.

## Dàn ý slide (8 trang gợi ý, kể cả bìa)
1. Bìa: Thư viện nạp lại code khi chạy
2. Ý tưởng: sửa code mà không tắt chương trình
3. Thư viện động là gì
4. Nạp hàm bằng dlopen / LoadLibrary
5. Phát hiện file đổi và nạp lại
6. Trạng thái giữa các lần nạp
7. Giới hạn và rủi ro
8. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Chương trình in một chuỗi; khi sửa chuỗi trong thư viện, chương trình in chuỗi mới.

## Ghi chú
- Làm slide theo chuẩn trong PHONG-CACH-SLIDE.md.
- Chỉ đưa vào app khi đã có bài đọc, bài tập có test và đã chạy thử bằng gcc.
- Trạng thái: chưa làm.
