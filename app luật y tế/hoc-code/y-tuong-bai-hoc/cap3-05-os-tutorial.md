# OS tutorial tối thiểu

**Cấp 3 · Nâng cao** · Nguồn: os-tutorial

## Mục tiêu
Đi qua các bước xây một OS nhỏ, từng bước có thể chạy.

## Dàn ý slide (7 trang gợi ý, kể cả bìa)
1. Bìa: OS tutorial tối thiểu
2. Bộ công cụ: trình biên dịch chéo, QEMU
3. Bước 1: boot và in chữ
4. Bước 2: gọi C từ assembly
5. Bước 3: quản lý ngắt
6. Bước 4: đọc bàn phím
7. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Hoàn thành bước 1–2 và chạy trên QEMU.
