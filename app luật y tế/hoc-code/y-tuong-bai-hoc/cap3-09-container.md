# Linux container trong 500 dòng

**Cấp 3 · Nâng cao** · Nguồn: Linux Containers in 500 LOC

## Mục tiêu
Hiểu container là gì: namespace, cgroup, chroot.

## Dàn ý slide (7 trang gợi ý, kể cả bìa)
1. Bìa: Linux container trong 500 dòng
2. Container không phải máy ảo
3. Namespace: tách tiến trình, mạng, file
4. Cgroup: giới hạn tài nguyên
5. Đổi thư mục gốc (chroot/pivot_root)
6. Chạy một shell trong container
7. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Chạy một lệnh trong thư mục gốc mới với PID riêng.
