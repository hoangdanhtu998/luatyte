# Tetris bằng C++

**Cấp 1 · Làm quen** · Nguồn: Tetris Tutorial in C++

## Mục tiêu
Tách logic game khỏi hiển thị; làm quen vòng lặp game và va chạm.

## Dàn ý slide (9 trang gợi ý, kể cả bìa)
1. Bìa: Tetris bằng C++
2. Tetris gồm những gì: lưới, khối, vòng rơi
3. Biểu diễn lưới bằng mảng 2 chiều
4. Khối tetromino và phép xoay
5. Kiểm tra va chạm trước khi di chuyển
6. Xóa dòng đầy và cộng điểm
7. Vòng lặp: nhận phím, cập nhật, vẽ
8. Tách logic khỏi giao diện để test được
9. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Hàm xoay khối và hàm kiểm tra va chạm, có test in ra terminal (không cần đồ họa).
