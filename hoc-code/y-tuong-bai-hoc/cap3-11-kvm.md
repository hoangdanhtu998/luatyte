# Học KVM bằng cách tự cài đặt

**Cấp 3 · Nâng cao** · Nguồn: Learning KVM

## Mục tiêu
Hiểu ảo hóa phần cứng qua giao diện /dev/kvm.

## Dàn ý slide (7 trang gợi ý, kể cả bìa)
1. Bìa: Học KVM bằng cách tự cài đặt
2. Ảo hóa phần cứng là gì
3. API KVM: mở, tạo máy ảo, tạo vCPU
4. Bộ nhớ khách và ánh xạ
5. Chạy vCPU và xử lý thoát (exit)
6. Thiết bị I/O đơn giản
7. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Tạo một máy ảo chạy đoạn mã in một ký tự.
