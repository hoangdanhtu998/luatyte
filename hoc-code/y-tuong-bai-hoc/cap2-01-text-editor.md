# Tự viết text editor trong terminal

**Cấp 2 · Trung bình** · Nguồn: Build Your Own Text Editor

## Mục tiêu
Quản lý buffer văn bản, xử lý phím, hiển thị có cuộn.

## Dàn ý slide (9 trang gợi ý, kể cả bìa)
1. Bìa: Tự viết text editor trong terminal
2. Editor làm được gì và cần những phần nào
3. Chế độ terminal: tắt echo, đọc từng phím
4. Buffer dòng: mảng con trỏ tới chuỗi
5. Con trỏ con (cursor) và di chuyển
6. Cuộn màn hình (viewport)
7. Mở, lưu file
8. Tìm kiếm đơn giản
9. Tổng kết và bước tiếp theo

## Bài tập luyện (trong khu Luyện tập)
Mở một file, di chuyển con trỏ bằng phím mũi tên, lưu lại khi bấm Ctrl+S.
