# Tự viết Redis bằng C/C++

**Cấp 3 · Nâng cao** · Nguồn: Build Your Own Redis

## Mục tiêu
Viết máy chủ kiểu Redis: giao thức, cấu trúc dữ liệu, mạng.

## Dàn ý slide (8 trang gợi ý, kể cả bìa)
1. Bìa: Tự viết Redis bằng C/C++
2. Redis làm gì
3. Giao thức RESP
4. Server nhận nhiều kết nối (event loop)
5. Cấu trúc dữ liệu: chuỗi, danh sách, băm
6. Lệnh SET, GET, DEL
7. Lưu xuống đĩa đơn giản
8. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Server nhận SET/GET qua TCP và trả lời đúng định dạng.
