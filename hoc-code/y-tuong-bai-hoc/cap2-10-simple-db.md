# Let's Build a Simple Database

**Cấp 2 · Trung bình** · Nguồn: Let’s Build a Simple Database

## Mục tiêu
Hiểu cách cơ sở dữ liệu lưu bảng và tìm kiếm.

## Dàn ý slide (9 trang gợi ý, kể cả bìa)
1. Bìa: Let's Build a Simple Database
2. Cơ sở dữ liệu làm gì
3. Dòng và trang bộ nhớ
4. Lưu bảng xuống đĩa theo trang
5. Câu lệnh đơn giản: insert, select
6. Tìm kiếm tuyến tính và chỉ số
7. Trình phân tích câu lệnh
8. Kiểm thử và giới hạn
9. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Hỗ trợ insert và select theo một cột, lưu được qua lần chạy.
