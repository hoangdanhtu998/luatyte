# Let's Write a Kernel

**Cấp 3 · Nâng cao** · Nguồn: Let’s Write a Kernel

## Mục tiêu
Viết kernel nhỏ: ngắt, bộ nhớ và tiến trình đơn giản.

## Dàn ý slide (7 trang gợi ý, kể cả bìa)
1. Bìa: Let's Write a Kernel
2. Kernel làm gì
3. Ngắt và bảng vector ngắt
4. Quản lý bộ nhớ cơ bản
5. Đa nhiệm đơn giản
6. Gọi hệ thống (system call)
7. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Xử lý một ngắt bàn phím và in ký tự.
