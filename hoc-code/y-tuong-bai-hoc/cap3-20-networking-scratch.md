# Networking from Scratch

## Mục tiêu
Tự xây các thành phần mạng cơ bản để hiểu cách hoạt động.

## Dàn ý slide (6 trang gợi ý, kể cả bìa)
1. Bìa: Networking from Scratch
2. Mạng từ góc nhìn người viết code
3. Socket và địa chỉ
4. Giao thức đơn giản tự thiết kế
5. Xử lý lỗi và timeout
6. Tổng kết

Một giao thức ping-pong tự thiết kế giữa hai chương trình.
