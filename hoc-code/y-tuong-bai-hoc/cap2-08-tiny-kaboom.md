# KABOOM! đồ họa nhỏ

**Cấp 2 · Trung bình** · Nguồn: Tiny KABOOM

## Mục tiêu
Thực hành đồ họa phần mềm và vòng lặp hình ảnh.

## Dàn ý slide (8 trang gợi ý, kể cả bìa)
1. Bìa: KABOOM! đồ họa nhỏ
2. Mục tiêu: vẽ bằng code, không thư viện
3. Hệ tọa độ màn hình
4. Vẽ hình và đường
5. Hoạt ảnh theo khung
6. Hiệu ứng nổ đơn giản
7. Xuất khung ra file
8. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Vẽ một hiệu ứng nổ theo 10 khung và xuất thành 10 file ảnh.
