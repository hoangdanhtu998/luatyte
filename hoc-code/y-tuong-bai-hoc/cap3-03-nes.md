# Lập trình game NES bằng C

**Cấp 3 · Nâng cao** · Nguồn: How to Program an NES Game in C

## Mục tiêu
Hiểu phần cứng máy chơi game cũ và cách viết game cho nó.

## Dàn ý slide (8 trang gợi ý, kể cả bìa)
1. Bìa: Lập trình game NES bằng C
2. NES và giới hạn phần cứng
3. Bộ nhớ và bộ xử lý 6502
4. Đồ họa: tile và bảng màu
5. Vòng lặp theo khung hình (VBlank)
6. Đọc phím điều khiển
7. Âm thanh cơ bản
8. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Hiển thị một sprite và di chuyển bằng phím điều khiển.
