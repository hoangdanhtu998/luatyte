# Viết bootloader bằng C

**Cấp 3 · Nâng cao** · Nguồn: Writing a Bootloader in C

## Mục tiêu
Hiểu quy trình khởi động và nạp kernel từ đĩa.

## Dàn ý slide (7 trang gợi ý, kể cả bìa)
1. Bìa: Viết bootloader bằng C
2. Bootloader là gì
3. Sector khởi động 512 byte
4. Đọc đĩa bằng BIOS
5. Nạp kernel vào bộ nhớ
6. Chuyển quyền điều khiển
7. Tổng kết

## Bài tập luyện (trong khu Luyện tập)
Bootloader đọc một sector và in dữ liệu ra màn hình.
