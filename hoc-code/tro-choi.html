Trò chơi

Chơi ngắn, mỗi ván 10 câu lấy ngẫu nhiên. Không cần máy chủ: bấm là chơi.

1. Đoán kết quả

Xem đoạn code C ngắn rồi chọn kết quả in ra đúng. Mỗi câu có 8 giây.

2. Tìm lỗi

Đoạn code có đúng một dòng sai. Chạm vào dòng đó. Mỗi câu có 12 giây.
